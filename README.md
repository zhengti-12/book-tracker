# book tracker

## vercel: [my-project-git-main-tiffany-zhengs-projects.vercel.app](https://my-project-git-main-tiffany-zhengs-projects.vercel.app)

## project summary: 

This is a personalized book trackers where users can enter new books and have a log for their books.

## features I chose to include: 

Starts off with user registration or login. This provides a memory for each user that saves the previous books they choose to log with this application. A book box appears so user can input the title, genre and date. It will pop up a form to give a new recommendation for every book they enter, or exit the pop up if the user doesn't want a recommendation. On the side of the add book block, there is a tracker for the number of books in each genre the user has read. Both login page and book logging page have a three color palette customization that users can choose from.
